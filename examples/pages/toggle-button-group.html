トグルボタングループ

component

押すと「選ばれた状態」が残るボタンを並べ、その場で表示や設定を切り替えます。1 つ選ぶと他が外れる単一選択（一覧 / グリッドなど表示形式の切り替え）と、それぞれ独立に ON / OFF する複数選択（太字 / 斜体などの書式）の 2 つのモードがあります。中身は ボタン と アイコンボタン の neutral ghost を薄い帯の中に並べるセグメント型で、選ばれたものだけが白いセグメントになります。選択状態は各ボタンの aria-pressed で示します。

単一選択

同じ内容の見え方を 1 つ選んで切り替える。data-selection="single" を目印に、押したボタンだけを aria-pressed="true" にする（選択中を押し直しても外さない）

<div class="[[toggle-btn-group]]" [[role="group"]] [[aria-label="表示形式"]] [[data-selection="single"]]>
  <button type="button" class="btn btn-md btn-neutral btn-ghost" [[aria-pressed="true"]]>一覧</button>
  <button type="button" class="btn btn-md btn-neutral btn-ghost" aria-pressed="false">グリッド</button>
  <button type="button" class="btn btn-md btn-neutral btn-ghost" aria-pressed="false">ボード</button>
</div>

複数選択

書式や表示オプションをそれぞれ独立に ON / OFF する。data-selection="multiple" で、押したボタンの aria-pressed を反転する（0 個選択も可）

<div class="toggle-btn-group" role="group" aria-label="文字の書式" [[data-selection="multiple"]]>
  <button type="button" class="[[icon-btn]] icon-btn-md icon-btn-neutral icon-btn-ghost" aria-pressed="true" [[aria-label="太字"]]>
    <svg class="icon icon-lg" aria-hidden="true"><use href="./icons.svg#lucide-bold"></use></svg>
  </button>
  …
</div>

アイコンだけの単一選択

狭い場所の表示切り替えは icon-btn を並べ、それぞれに選択肢名の aria-label を付ける。見える名前も要るならボタンを ツールチップ で包む

1 行に 1 件ずつ表示 カードを格子状に表示 日付ごとに表示 
<div class="toggle-btn-group" role="group" aria-label="表示形式" data-selection="single">
  <span class="[[tooltip]]">
    <button type="button" class="icon-btn icon-btn-md icon-btn-neutral icon-btn-ghost" aria-pressed="true"
            [[aria-label="一覧"]] aria-describedby="tip-list">
      <svg class="icon icon-lg" aria-hidden="true"><use href="./icons.svg#lucide-list"></use></svg>
    </button>
    <span class="tooltip-content" id="tip-list" role="tooltip">1 行に 1 件ずつ表示</span>
  </span>
  …
</div>

見え方を変えるならトグル、中身を変えるならタブ

用途の使い分け
Good

同じ案件の一覧を、行・カード・地図のどれで見るかを選ぶ。中身は変わらず、見え方だけが変わる。

<div class="[[toggle-btn-group]]" role="group" aria-label="表示形式" data-selection="single">
  <button class="btn btn-md btn-neutral btn-ghost" [[aria-pressed="true"]]>一覧</button>…
</div>
Don't

概要・財務情報・担当者は別々の情報。表示する中身（パネル）を切り替えるなら タブ（tabpanel で出し分ける）。

<!-- 別の情報の出し分けに toggle-btn-group を使わない → role="tablist" のタブ -->
<div class="[[toggle-btn-group]]"><button aria-pressed="true">[[概要]]</button>…</div>

一覧の絞り込みには使わない

用途の使い分け
Good

案件を状態で絞り込むなら フィルターチップ。件数が見え、何件に絞られるかが分かる。

<button type="button" class="[[filter-chip]]" aria-pressed="true">…公開中…12件…</button>
Don't

トグルボタンは見え方や書式の切り替え用。絞り込みに使うと件数を出せず、他の絞り込みとの組み合わせ方も伝わらない。

<!-- 一覧の絞り込みに toggle-btn-group を使わない → filter-chip / tab -->
<div class="[[toggle-btn-group]]" aria-label="状態"><button aria-pressed="true">公開中</button>…</div>

単一選択は常に 1 つを選んでおく

状態の一貫性
Good

初期表示から 1 つを選んでおき、選択中を押し直しても外さない。いまどの並びで見ているかが常に分かる。

<button … [[aria-pressed="true"]]>新着順</button>
<button … aria-pressed="false">更新順</button>
Don't

どれも選ばれていないと、いまの並びが何なのか分からない。

<!-- 単一選択で全部 false にしない -->
<button … [[aria-pressed="false"]]>新着順</button>
<button … [[aria-pressed="false"]]>更新順</button>

トグルボタングループのアクセシビリティ

中はネイティブの <button> のままで、選択状態は各ボタンの aria-pressed、グループ名は role="group" ＋ aria-label で伝えます。見た目は aria-pressed から決まるので、状態と表示がずれません。WCAG 2.2 全基準は アクセシビリティ ページを参照。

期待される配慮

Presentation / Adaptability / Interaction / Assistive Technology

提示

選択は白いセグメントと文字の濃さ（fg/low → fg/high）の 2 つで示す。白と帯（neutral/50）の差はごく小さいため、文字の濃さの差（3.75:1）で色に頼らず区別できるようにしている。

適応

並べる数は 2〜5 個に抑え、320px 幅でも 1 行に収める。収まらないならアイコンだけにするか select にする。

操作

各ボタンが Tab で止まり、Enter / Space で切り替える。切り替えはその場の表示だけを変え、ページ遷移や送信を起こさない。

支援技術

グループ名（「表示形式、グループ」）に続いて「一覧、切り替えボタン、押されています」のように、各ボタンの名前と押下状態が読まれる。

DS が担保する機能

追加実装なしで満たされる

  • ✓選択中の見た目は aria-pressed="true" から決まる（クラスで別に管理しないので、状態と表示がずれない）
  • ✓非選択の文字 fg/low は帯（neutral/50）の上で 4.55:1、hover（白）で 4.76:1。選択中の文字 fg/high は白いセグメントの上で 17.9:1
  • ✓強制カラーモードでは選択中のボタンを Highlight で塗り、非選択との区別を保つ
  • ✓中はネイティブ <button> のまま。フォーカスリング（info/600）とターゲット最小 24px は btn / icon-btn のとおり

実装時の必須対応

プロダクト側で担保する

  • !グループに role="group" と aria-label（何を切り替えるか）を付ける
  • !押されたら aria-pressed を書き換える。単一選択は押したボタンを true・他を false にし、選択中を押し直しても外さない
  • !アイコンだけのボタンには選択肢名の aria-label を付け、SVG は aria-hidden="true"。「一覧（選択中）」のように状態を名前に含めない

テスト方法

スクリーンリーダー / キーボード / 自動チェック

  • SRグループ名と、各ボタンの名前・押下状態（押されています / 押されていません）が読まれる。切り替えると状態の読み上げも変わる
  • キーTab で各ボタンに止まり、Space で切り替わる。単一選択は常に 1 つだけが選択中になる
  • 自動axe / Lighthouse でボタンの名前（icon-btn の aria-label）とコントラストを確認

選択状態は aria-pressed で伝える

達成基準：WCAG 4.1.2 名前（name）・役割（role）及び値（value）
Good

「太字、切り替えボタン、押されています」と、名前と状態が別々に読まれる。

<button class="icon-btn …" [[aria-pressed="true"]] [[aria-label="太字"]]>…</button>
Don't

クラスや名前の文言で状態を表すと、支援技術には「切り替えボタン」だと伝わらず、白いセグメントにもならない。

<!-- 状態をクラスや aria-label の文言で表さない -->
<button class="icon-btn … [[is-selected]]" [[aria-label="太字（選択中）"]]>…</button>
