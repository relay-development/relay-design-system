メニュー

component

縦に項目を並べる汎用メニューです。いま開いているページを示しながら移動できるナビゲーション（サイドナビ）にも、設定・ログアウトなどの操作を並べるアクションメニューにも使えます。幅は親要素で決めます（サイドナビ用途は w-70 = 280px が目安）。

項目の状態

default / hover / focus / current。hover と current は同じ見た目（背景 primary/50 + 太字）

default
  • メニュー項目
hover
  • メニュー項目
focus
  • メニュー項目
current
  • メニュー項目

使用例: ナビゲーション（サイドナビ）

nav 要素で包み、現在地に aria-current="page"。グループは .menu-divider で区切る

  • アカウント設定
