ボタンを押すと開くポップアップに、その対象に対する操作（編集・複製・削除など）を並べるメニューです。ネイティブの Popover API で最前面に開くため、カードの中から開いても切れません。項目は メニュー の menu-item を再利用します。

Good

対象に対する操作を並べ、取り消せない操作は danger にして区切り線の下・末尾に置く。

Don't

ページ移動はリンク（menu のナビ）、並び替えなど値の選択は select / tab に分ける。メニューに畳むと現在の状態が見えなくなる。

アクションメニューのアクセシビリティ

relay のアクションメニューは WAI-ARIA APG の Menu Button パターン（トリガー aria-haspopup="menu" ＋ role="menu" / menuitem）です。開閉・Esc・外側クリックでの閉じはネイティブの Popover API が担い、フォーカス移動と矢印キー操作は小さな JS で付与します。WCAG 2.2 全基準は アクセシビリティ ページを参照。

期待される配慮

Presentation / Adaptability / Interaction / Assistive Technology

提示

メニューは影と輪郭線で背景から浮かせる。danger は色だけに頼らず「削除」などラベルで操作内容を示す。無効項目は消さずに薄く残す。

適応

下に空きが無ければ上に開き、画面端から 16px は空ける。項目が多いときはメニュー内でスクロールする。

操作

クリック / Enter / Space / ↓ で開き、↑ ↓ で移動、Enter で実行、Esc で閉じてトリガーに戻る。hover では開かない。

支援技術

トリガーは「メニュー ポップアップ ボタン、折りたたみ / 展開」と読まれ、開くとメニュー名と項目数、各項目の名前が読まれる。

DS が担保する機能

追加実装なしで満たされる

  • ✓Popover API による最前面表示・Esc と外側クリックでの閉じ・閉じた後のフォーカス復帰
  • ✓フォーカスリング --shadow-focus-ring ＋ フォーカス中項目の背景ハイライト
  • ✓danger は negative/700（白地・negative/50 地とも AA）、無効は fg-disabled で hover しない
  • ✓強制カラーモードで輪郭線を CanvasText、無効項目を GrayText にする

実装時の必須対応

プロダクト側で担保する

  • !トリガーに aria-haspopup="menu" と aria-expanded、メニューに role="menu" と aria-labelledby、項目に role="menuitem" と tabindex="-1"
  • !icon-btn のトリガーは aria-label に対象を含めて一意化する（例: 『プロジェクト A』のメニュー）
  • !開閉に合わせた aria-expanded の同期・先頭項目へのフォーカス・矢印キー移動・位置計算を JS で付与する（実装例は catalog.js の Action Menu ハンドラ）
  • !無効項目は aria-disabled="true"（disabled 属性にしない。フォーカスを残して存在を伝える）
