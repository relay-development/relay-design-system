マルチセレクター

component

決まった選択肢から複数を選ぶ、折りたたみ式の入力欄です。見た目は セレクター と同じ枠のボタンで、押すとパネルが開き、中の チェックボックス で選びます。選んだ値はボタンに要約して表示します。パネルの中は普通のチェックボックスなので、Tab で移動・Space で切り替えでき、フォームの送信にもそのまま乗ります。

基本

ボタンを押すとパネルが開き、チェックボックスで選ぶ。選んだその場でボタンの表示（名前を「、」でつなぐ）に反映する。ほぼ全部を選ぶことが多いなら先頭に「すべて」（一部だけ選ぶと一部選択の表示）

選択肢に種類があるなら fieldset ＋ legend.multi-selector-group-title で分ける。ツールバーなど幅が狭い場所は data-summary="count" で「3 件選択」と出す

マルチセレクターのアクセシビリティ

パネルの中は普通のチェックボックスです。矢印キーで動く独自の一覧（listbox）にしないので、特別なキー操作を覚えなくても Tab と Space で選べ、スクリーンリーダーでも「チェックボックス、チェックあり」と標準どおりに読まれます。WCAG 2.2 全基準は アクセシビリティ ページを参照。

期待される配慮

Presentation / Adaptability / Interaction / Assistive Technology

提示

ボタンに選んだ値の名前（または件数）を出し、パネルを開かなくても何を選んでいるか分かる。

適応

パネルは最大 320px で縦にスクロールし、画面の端では内側に収まる。

操作

ボタンで開くと最初のチェックボックスへフォーカス。Tab で移動・Space で切り替え、Esc で閉じてボタンへ戻る。Tab でパネルの外へ出ても閉じる。

支援技術

ボタンは「表示する列、振込日、振込先、金額、ボタン、折りたたみ」のように項目名と選んだ値が読まれる。パネルは項目名のダイアログ、中は標準のチェックボックス。

DS が担保する機能

追加実装なしで満たされる

  • ✓ボタンはセレクターと同じ枠・高さ・フォーカスリング（info/600）。未選択の placeholder は data-placeholder の文字を CSS で出す
  • ✓選択肢の行全体が押せる（label で包んだ checkbox）。hover で地が付く
  • ✓強制カラーモードでは矢印を system color で描き直し、パネルの輪郭線を出す

実装時の必須対応

プロダクト側で担保する

  • !ボタンに aria-labelledby（項目名 ＋ 選んだ値）、aria-haspopup="dialog"、aria-expanded（開閉で更新）
  • !パネルは role="dialog" と aria-labelledby。グループは fieldset ＋ legend
  • !開いたら最初のチェックボックスへフォーカス、閉じたらボタンへ戻す。Tab でパネルの外へ出たら閉じる
  • !選ぶたびにボタンの要約を更新し、「すべて」は一部だけ選ぶと indeterminate にする

テスト方法

スクリーンリーダー / キーボード / 自動チェック

  • SRボタンで項目名と選んだ値が読まれ、開いたパネルで各チェックボックスの状態が読まれる
  • キーEnter / Space で開き、Tab と Space だけで選べる。Esc で閉じるとボタンにフォーカスが戻る
  • 自動axe / Lighthouse でボタンの名前・チェックボックスのラベル・コントラストを確認
