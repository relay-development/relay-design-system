テーブル

component

列ごとの項目名を上に並べて、複数のデータを行で比較するテーブルです。1 件の詳細を縦に並べて見せるときはシンプルテーブルを使います。

基本

項目名の行（thead）が上、データ行（tbody）が下。値が無いセルは — を text-fg-middle で表示（10.35:1、WCAG AAA）

列幅 — 締める列だけ指定し、自由文に余白を渡す

固定書式の列（日付・状態・金額・操作）は data-table-fit（数値は data-table-num）を th と同列の td 全てに付けて内容幅に締める。自由文は data-table-text の 1 列。列が多く収まらないときは data-table-wrap（tabindex="0"）で包んで横スクロール — 列幅を詰めて無理に収めない

見出し行 — タイトルと、件数・表全体への操作

data-table-header の 1 段目にタイトル、2 段目（data-table-toolbar）の左に表示件数、右に「検索 → アイコンの操作（3 個まで）→ 主操作」を sm でそろえて並べる。検索は虫眼鏡か Enter で確定してから絞り込み（入力のたびには変えない）、絞り込みのパネルには複数の列や列に無い条件（振込月）をまとめる。適用中の条件は操作の行の下にトークンで並べ、× で 1 つずつ、「すべて解除」でまとめて解除できる。1 列の値だけで絞るなら列フィルター、並べ替えは列見出し

    テーブルのアクセシビリティ

    ネイティブ <table> ベース。列見出しに <th scope="col">、表の名前に <caption>、空セルは —、幅広なら横スクロールで reflow を担保します。WCAG 2.2 全基準は アクセシビリティ ページを参照。

    期待される配慮

    Presentation / Adaptability / Interaction / Assistive Technology

    提示

    見出し行とデータ行を視覚的に区別。空セルは空白でなく —（fg/middle・AAA）で「値なし」を明示。

    適応

    幅が足りない時は横スクロールで内容を保持（reflow）。文字は rem で拡大に追従。

    操作

    横スクロール領域はキーボードでもスクロールできるようにする（フォーカス可能なコンテナ等）。

    支援技術

    <th scope="col"> で列とデータの対応が読まれる。<caption> か aria-label で表に名前を付ける。

    DS が担保する機能

    追加実装なしで満たされる

    • ✓ネイティブ <table>／thead／tbody のセマンティック構造
    • ✓見出し行とデータ行のコントラスト・区切りを確保
    • ✓空セルの — は fg/middle（10.35:1・AAA）で可読
    • ✓カタログでは狭幅時に card-body が横スクロール（reflow の下地）

    実装時の必須対応

    プロダクト側で担保する

    • !列見出しを <th scope="col"> にする（データセルは td）
    • !表に <caption> か aria-label で名前を付ける
    • !空セルは空白にせず —（またはテキスト）で「値なし」を示す
    • !幅広なテーブルは overflow-x: auto のコンテナで包み、キーボードでもスクロールできるようにする
    • !並べ替えは見出しの文字ごと <button> にし、並べ替え中の th にだけ aria-sort（ascending / descending）を付ける。結果は aria-live="polite" で告知する
    • !列フィルターのトリガーに aria-label（「役割で絞り込む」）・aria-haspopup="dialog"・aria-expanded を付け、絞り込み中は aria-label に適用中の値を含める
    • !列フィルターのパネルは role="dialog" と aria-label。開いたら select へフォーカスし、閉じたらトリガーへ戻す
    • !絞り込み結果の件数を aria-live="polite" の領域で告知する（行が消えたことは画面を見ないと分からない）

    テスト方法

    スクリーンリーダー / 拡大・リフロー / 自動チェック

    • SR各セルで対応する列見出しが読まれる（「状態、公開中」等）。表の名前が読まれる
    • SR列フィルターを適用すると「全 8 件中 3 件を表示」が読まれる。トリガーは「役割で絞り込む（適用中: 管理者）」と読まれる
    • SR並べ替えの見出しは「更新日、ボタン、昇順で並べ替え済み」のように読まれ、押すと「更新日の降順で並べ替えました」と告知される
    • キートリガーで Enter / Space → select にフォーカス、Tab で「リセット」「適用」、Esc で閉じてトリガーに戻る
    • 拡大320px 幅・200% 拡大で、横スクロールを許容しつつ情報が欠けない
    • 自動axe / Lighthouse で th／scope・caption・コントラストを確認
