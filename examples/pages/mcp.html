MCP サーバー

AI コーディングツール連携

AI（Claude Code / Cursor / Windsurf など）で UI を書くとき、relay デザインシステムのコンポーネント仕様・トークン・必須ルールを AI に直接読ませるための MCP（Model Context Protocol）サーバーを npm パッケージに同梱しています。AI ツールの設定に 1 行登録するだけで、ハードコード値や規約違反（text-sm 直書きなど）を避けた relay 準拠の UI を生成しやすくなります。

セットアップ

このパッケージには relay-ds-mcp という stdio MCP サーバーが含まれています。利用するツールの MCP 設定に登録してください。

AI にセットアップを依頼する

手っ取り早く始めたいとき。下のプロンプトをコピーして、お使いの AI ツール（Claude Code / Cursor など）にそのまま貼り付けてください

relay デザインシステムの MCP サーバーをこのプロジェクトで使えるようにセットアップして。

プロジェクト直下の .mcp.json に次の設定を追加してください（ファイルが無ければ新規作成）:

{
  "mcpServers": {
    "relay-ds": {
      "command": "npx",
      "args": ["-y", "--package=@light-right/design-system", "relay-ds-mcp"]
    }
  }
}

追加できたら relay-ds の list_components ツールが使えるか確認し、以降は relay デザインシステムのトークン・コンポーネント・規約に準拠して UI を実装して。

手動で設定する（Claude Code）

プロジェクト直下の .mcp.json に追記

{
  "mcpServers": {
    "relay-ds": {
      "command": "npx",
      "args": ["-y", "--package=@light-right/design-system", "relay-ds-mcp"]
    }
  }
}

すでにプロジェクトへ npm install @light-right/design-system 済みなら、command を "relay-ds-mcp"（引数なし）にしてローカル版を直接起動できます。Cursor / Windsurf も各ツールの MCP 設定に同じコマンドを登録すれば使えます。

使えるツール

登録すると、AI から次の 5 つのツールが使えるようになります。「relay のスタイルでログイン画面を作って」のように頼むと、AI がこれらを呼び出して規約準拠の UI を生成します。

ツール内容
list_components全コンポーネント一覧（英名 / 和名 / 概要 / 主要クラス）
get_component指定コンポーネントの完全仕様（props・状態・色・usage・クラス・コピペ HTML・Figma リンク）
get_tokensデザイントークン（color / typography / spacing / radius / shadow）
get_design_principles必須ルール（ハードコード禁止・semantic color 等）+ 禁止パターン Top 10
searchコンポーネント / トークン / 規約の横断検索

公開データは DESIGN.md / src/components / src/tokens / snippets から自動生成されるため、デザインシステム本体を更新すれば MCP の応答も追従します。
