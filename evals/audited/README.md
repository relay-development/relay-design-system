# audited — 監査済み判定の生成物スナップショット（コミット対象・公開される）

[review-log.md](../review-log.md) の監査記録の各行から参照される、**監査時に採点対象だった HTML** のコピー。
カタログの監査ログページはビルド時にこのディレクトリを `eval-outputs/` として同梱し、
各行の「画面」リンクから開けるようにする。

## 運用

- 監査を記録したら、その判定が見ていた HTML を `evals/results/outputs/<実行スタンプ>/<お題>.html`
  （アーカイブ）からここへ `<監査日>-<お題>.html` の名前でコピーし、review-log.md の行からリンクする
- **このディレクトリは公開 GitHub Pages に載る**。コピー前に固有名詞・実在の人名等の
  ダミーデータが混ざっていないか確認し、あれば架空の値に置換して下の注記に残す
- ファイルは `./relay.css` を参照する（ビルドが同じディレクトリに配布 CSS を置く）

## 置換の注記

- `2026-08-17-settings-nav.html`: プロフィール入力のダミー値の人名を架空名（山田 花子）に置換
  （監査時の判定に影響しない箇所）
